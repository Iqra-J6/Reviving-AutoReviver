# AutoReviver - The Trusted Marketplace

AutoReviver is a modern automotive marketplace platform built for buying, selling, and managing vehicle parts with ease. It provides a clean and responsive experience for discovering new, used, maintenance, and modification parts, along with a secure user dashboard for managing listings, messages, and account settings.

---

## 🚀 Features

- Browse automotive parts by category  
- Buy and sell vehicle parts  
- Categories include:
  - New Parts  
  - Used Parts  
  - Maintenance Parts  
  - Modification Parts  
- User authentication (Login & Signup)  
- Interactive user dashboard  
- Messaging system  
- Garage management  
- Verification workflow  
- Responsive modern UI  
- Smooth animations with Framer Motion  

---

## 🛠 Tech Stack

**Frontend**
- React 19  
- TypeScript  
- Vite  
- TanStack Router  
- TanStack Query  
- Tailwind CSS  
- Radix UI  
- Framer Motion  

**Backend & Services**
- Supabase  
- Cloudflare Vite Plugin
